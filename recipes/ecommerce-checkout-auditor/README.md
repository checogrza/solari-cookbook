# Autonomous E-Commerce & Checkout Auditor (Powered by Solari)

An autonomous AI agent running in a Solari browser sandbox that performs end-to-end checkout validation, promo code assertions, and automated QA reporting for online storefronts.

## Features
- Autonomous store navigation and catalog DOM inspection.
- SKU selection and cart drawer state validation.
- Promo engine discount calculations.
- Instant markdown reporting with latency and error metrics.

## Quickstart
```bash
pip install -r requirements.txt
python main.py
```

The output report is generated under `results/audit_report.md`.
